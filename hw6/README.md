### **Описание**

#### **Роли: Поставщик, Заказчик, Администратор** 

#### **Эндпоинты для заказчика**

| HTTP Метод | URL                                   | Описание                                                   |
| ---------- | ------------------------------------- | ---------------------------------------------------------- |
| `GET`      | `/suppliers/`                         | Список всех поставщиков.                                   |
| `GET`      | `/suppliers/?param1=&param2=&param3=` | Фильтрация поставщиков по некоторым полям.                 |
| `GET`      | `/orders/`                            | Список всех заказов, связанных с заказчиком.               |
| `POST`     | `/orders/`                            | Создание нового заказа.                                    |
| `PUT`      | `/orders/{id}/`                       | Обновление информации о заказе.                            |
| `DELETE`   | `/orders/{id}/`                       | Удаление заказа.                                           |
| `GET`      | `/orders/{id}/recommend_suppliers/`   | Получение рекомендаций поставщиков для конкретного заказа. |
| `POST`     | `/recomendation`                      | Получение списка рекомендуемых поставщиков                 |
| `POST`     | `/recomendation?top_only=true`        | Получение самого рекомендуемого поставщика                 |

---

#### **Эндпоинты для поставщика**

| HTTP Метод | URL                | Описание                            |
| ---------- | ------------------ | ----------------------------------- |
| `POST`     | `/suppliers/`      | Регистрация нового поставщика.      |
| `PUT`      | `/suppliers/{id}/` | Редактирование данных о поставщике. |
| `DELETE`   | `/suppliers/{id}/` | Удаление поставщика.                |

---

#### **Эндпоинты для администратора**

| HTTP Метод | URL                            | Описание                                   |
| ---------- | ------------------------------ | ------------------------------------------ |
| `GET`      | `/users/`                      | Получение списка всех пользователей.       |
| `PUT`      | `/users/{id}/`                 | Редактирование данных пользователя.        |
| `DELETE`   | `/users/{id}/`                 | Удаление пользователя.                     |
| `GET`      | `/orders/`                     | Список всех заказов.                       |
| `POST`     | `/orders/`                     | Создание заказа.                           |
| `PUT`      | `/orders/{id}/`                | Обновление информации о заказе.            |
| `DELETE`   | `/orders/{id}/`                | Удаление заказа.                           |
| `GET`      | `/suppliers/`                  | Список всех поставщиков.                   |
| `POST`     | `/suppliers/`                  | Добавление нового поставщика.              |
| `PUT`      | `/suppliers/{id}/`             | Редактирование данных поставщика.          |
| `DELETE`   | `/suppliers/{id}/`             | Удаление поставщика.                       |
| `POST`     | `/recomendation`               | Получение списка рекомендуемых поставщиков |
| `POST`     | `/recomendation?top_only=true` | Получение самого рекомендуемого поставщика |
